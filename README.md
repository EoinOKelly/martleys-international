# Martley International

Static transport website for Martley International / Portlaoise Logistics.

## Preview

Serve `dist/` with any static HTTP server. For example:

```sh
npx serve dist
```

## Content and assets

- Site copy is adapted from `Portlaoise Logistics Website Content Draft.docx` supplied for this project. Its draft placeholders for fleet counts, testimonials and environmental figures have been omitted.
- Freight and team photography was supplied within that draft document.
- `dist/assets/hero.mp4` is a compressed excerpt of the supplied `Martleys Website Home Page Video.mp4`. It shows the coach business and is a temporary hero until a freight-specific video is available.
- The contact buttons use a `mailto:` link; there is no backend form.
